# Lead security architect - upskill resources

This page focuses on learning and growth resources for the work role of lead security architect.

- The resources include links to online courses, blogs, research articles, videos, and books.

- These help with job upskilling, work training, professional development, and career advancement.

- These are intended to be good starting points, not a comprehensive catalogue.

At this role level you undertake complex, high risk work across several projects, interact with senior stakeholders across departments, research and apply innovative security architecture solutions, and develop vision, principles and strategy for security architects. The resources below emphasise advanced architecture, influence and strategy.

We welcome constructive feedback to improve this page and these lists.

- GitHub issues and/or pull requests are welcome.

- The resources are found via AI searches then go through human-in-the-loop proofing.

## Coursera courses

- [Cybersecurity Architecture Fundamentals](https://www.coursera.org/learn/packt-cybersecurity-architecture-fundamentals-jpld2): Covers integrating TOGAF, Zachman and SABSA frameworks into enterprise security strategy, and treats SABSA as a leading framework for business-driven security architecture.

- [Fundamentals of Information System Security Architecture](https://www.coursera.org/learn/information-system-security-architecture-first-course-1): Provides an in-depth look at key security architecture frameworks including the Sherwood Applied Business Security Architecture, zero trust and defence in depth strategies.

- [Security Architecture and Engineering](https://www.coursera.org/learn/packt-security-architecture-and-engineering-f4vdz): Aligned with the CISSP curriculum, covering the design and securing of IT environments including secure design principles, cryptography and physical security.

## Udemy courses

- [Security Architecture and Review with Threat Modeling: Hands On](https://www.udemy.com/course/security-architecture-and-design-review-with-threat-modeling/): Covers designing and implementing secure systems, identifying security threats and mitigating them through a structured architecture and design review process.

- [Cybersecurity Solution Architecture 201](https://www.udemy.com/course/cybersecurity-solution-architecture-201/): Moves from foundational controls to enterprise-scale design across thirteen modules, refining threat modelling skill with STRIDE, PASTA and MITRE ATT&CK.

- [Cyber Security Architecture Fundamentals](https://www.udemy.com/course/cyber-security-architecture-fundamentals/): Covers principles and best practice for designing security architectures, including threat modelling, risk assessment, security design patterns, access control, cryptography, network security, cloud security and incident response.

## Skillsoft courses

- [Courses for Security Architect](https://www.skillsoft.com/journey/security-architect-5ab7fde5-80f9-4602-9049-c9094b776589): A curated learning journey for the security architect role, spanning secure design principles, architecture models and risk.

- [Defensible Security](https://www.skillsoft.com/course/defensible-security-4325f320-efc3-45ba-956d-6829c2b8160d): Explores defensible architecture and zero trust models from the standpoint of a security architect, covering the tools that address network security challenges and reviewing common security models and standards.

- [Zero Trust Networking Bootcamp](https://www.skillsoft.com/channel/zero-trust-networking-bootcamp-88ff8309-cdfc-4bd6-96d1-6b4a36aac02d): A crash course in which Michael J. Shannon demystifies zero trust architectures and gives real-world guidance for launching or improving a zero trust initiative while avoiding common pitfalls.

## edX courses

- [Cyber Defense Architecture (IBM)](https://www.edx.org/learn/computer-science/ibm-cybersecurity-architecture): Builds job-ready skills in cyber defence architecture with hands-on experience of the tools and practices employers look for.

- [Cybersecurity Risk Management (RITx)](https://www.edx.org/course/cybersecurity-risk-management): Teaches the risk management framework with qualitative and quantitative assessment, covering risk analysis, assessment and mitigation, identifying threats and vulnerabilities, determining risk level, defining controls and conducting cost-benefit or business impact analysis.

## MIT OpenCourseWare courses

- [6.5660 Computer Systems Security](https://ocw.mit.edu/courses/6-5660-computer-systems-security-spring-2024/): Covers design and implementation of secure computer systems, including attacks that compromise security and techniques for achieving it, spanning operating system security, privilege separation, capabilities, language-based security, cryptographic network protocols, trusted hardware, and web and mobile security.

- [6.857 Network and Computer Security](https://ocw.mit.edu/courses/6-857-network-and-computer-security-spring-2014/): An upper-level course on network and computer security covering the underlying primitives and their composition into systems.

- [6.858 Lecture 1: Introduction and Threat Models](https://ocw.mit.edu/courses/6-858-computer-systems-security-fall-2014/resources/lecture-1-introduction-threat-models/): A concise treatment of what a threat model is and why the discipline depends on getting it right, with lecture materials freely available.

## Blog posts

- [Designing secure access with ZTNA](https://www.ncsc.gov.uk/blogs/designing-secure-access-with-ztna): National Cyber Security Centre guidance on designing zero trust network access architectures aligned with zero trust principles, aimed at architects, security practitioners and technical decision makers.

- [NCSC zero trust principles](https://nocomplexity.com/documents/securityarchitecture/architecture/NCSC-zerotrustprinciples.html): A structured presentation of the NCSC's eight zero trust design principles, from knowing your architecture through to choosing services designed for zero trust.

- [NCSC publishes Zero Trust architecture design principles](https://cybersecurity.jiscinvolve.org/wp/2021/07/23/ncsc-publishes-zero-trust-architecture-design-principles/): Summarises the eight principles and what adopting them means in practice for a UK public sector organisation.

- [A zero trust approach to security architecture (ITSM.10.008)](https://www.cyber.gc.ca/en/guidance/zero-trust-approach-security-architecture-itsm10008): Canadian Centre for Cyber Security guidance offering a second national perspective on the same architectural shift.

- [Zero Trust is not just an architecture](https://www.nexor.com/blog/zero-trust-is-not-just-an-architecture): Argues that secure by design means building security from the outset as the core of a system rather than bolting it on, and that zero trust is as much organisational as architectural.

- [Zero Trust Is Not a Product: Here's What Implementation Actually Looks Like](https://intelligentvisibility.com/blog/zero-trust-implementation-enterprise-architecture): A practitioner account of what zero trust implementation actually requires, covering segmentation design and enforcement.

- [Zero trust architecture: best practices and lessons learned](https://zensec.co.uk/blog/zero-trust-architecture-best-practices-and-lessons-learned/): Collected lessons from zero trust programmes, including the common causes of stalled implementations.

- [STRIDE Threat Model Explained: Framework, Examples and How to Apply It](https://www.softwaresecured.com/post/stride-threat-modelling): A practical explanation of the six STRIDE categories with worked examples of applying them to a design.

- [Uncover Security Design Flaws Using the STRIDE Approach](https://learn.microsoft.com/en-us/archive/msdn-magazine/2006/november/uncover-security-design-flaws-using-the-stride-approach): The original MSDN article introducing STRIDE to a wide audience, still one of the clearest treatments available.

- [Network Segmentation Architecture and Implementation Guide](https://www.sentinelone.com/cybersecurity-101/cybersecurity/network-segmentation/): Covers segmentation approaches including zero trust microsegmentation and how it interacts with other policy control mechanisms.

## Research articles

- [A descriptive study of Microsoft's threat modeling technique](https://dl.acm.org/doi/10.1007/s00766-013-0195-2): Published in Requirements Engineering, this is the empirical evaluation of STRIDE that the field lacked, involving 57 final-year computer science master's students and quantifying cost and effectiveness.

- [strideSEA: A STRIDE-centric Security Evaluation Approach](https://arxiv.org/pdf/2503.19030): Integrates STRIDE as the central classification scheme across threat modelling, attack scenario analysis, risk analysis and countermeasure recommendation within a secure development lifecycle.

- [Threat modeling: uncover security design flaws using the STRIDE approach](https://www.researchgate.net/publication/291127084_Threat_modeling-uncover_security_design_flaws_using_the_stride_approach): The foundational description of the STRIDE technique and its application to design review.

- [STRIDE-based threat Modeling of Cybersecurity Risks in Local Computer Networks](https://www.researchgate.net/publication/398831878_STRIDE-based_threat_Modeling_of_Cybersecurity_Risks_in_Local_Computer_Networks): Applies STRIDE to local network models, identifying the gap between theoretical threat models and their practical implementation.

- [A STRIDE Model based Threat Modelling using Unified and-Or Fuzzy Operator for Computer Network Security](https://www.researchgate.net/publication/318611364_A_STRIDE_Model_based_Threat_Modelling_using_Unified_and-Or_Fuzzy_Operator_for_Computer_Network_Securit): Extends STRIDE with fuzzy operators to handle uncertainty in threat likelihood assessment.

- [Architecture-Derived CBOMs for Cryptographic Migration: A Security-Aware Architecture Tradeoff Method](https://arxiv.org/pdf/2603.22442): Addresses cryptographic bills of materials and architecture-level trade-offs, directly relevant to post-quantum migration planning.

- [Software defined networking architecture, traffic management, security, and placement: A survey](https://www.sciencedirect.com/science/article/abs/pii/S1389128621001481): A Computer Networks survey covering the security implications of software-defined network architecture.

- [Enterprise Architecture and IT Governance to Support the BizDevOps Approach: a Systematic Mapping Study](https://link.springer.com/article/10.1007/s10796-024-10473-2): Maps the literature on architecture and governance in continuous delivery environments, where security architecture must operate at delivery speed.

- [Stakeholder Perception of Enterprise Architecture](https://www.researchgate.net/publication/220757098_Stakeholder_Perception_of_Enterprise_Architecture): Finds stakeholders often perceive architecture management as abstract and hard to comprehend, a problem security architects face acutely when advising delivery teams.

- [Achieving benefits with enterprise architecture](https://www.sciencedirect.com/science/article/abs/pii/S0963868716302360): Argues that architecture benefits come mainly from the advisory services architecture enables, which reframes how a security architecture function should be measured.

## Books on Amazon

- [Threat Modeling: Designing for Security](https://www.amazon.com/Threat-Modeling-Designing-Adam-Shostack-ebook/dp/B00IG71FAS): By Adam Shostack. The standard work on building security into the design of software, services and systems from the beginning, structured around a four-question framework.

- [Threat Modeling: Designing for Security in an AI World](https://www.amazon.com/Threat-Modeling-Designing-Adam-Shostack/dp/1394413327): Shostack's updated edition, revising the four-question framework and adding techniques drawn from a decade of practice, including AI systems.

- [Enterprise Security Architecture: A Business-Driven Approach](https://www.amazon.com/Enterprise-Security-Architecture-Business-Driven-Approach/dp/1032099895): By John Sherwood, Andrew Clark and David Lynas. The definitive treatment of SABSA, the business-driven security architecture framework.

- [Zero Trust Security: A Complete Guide](https://www.skillsoft.com/book/zero-trust-security-a-complete-guide-7dd9c646-3fc2-4528-866f-e2f21ce5168d): Covers practical guidelines and requirements for designing and executing a zero trust journey, moving from perimeter-centric to identity-centric, policy-based approaches.

- [Top-Down Network Design](https://www.amazon.com/Top-Down-Network-Design-Networking-Technology-ebook/dp/B0040EK6OM): By Priscilla Oppenheimer. Useful for security architects who must reason about the network substrate their controls depend on.

- [Computer Networking: A Top-Down Approach](https://www.amazon.com/Computer-Networking-Top-Down-Approach-Kurose-ebook/dp/B0FP1SXZV3): Kurose and Ross. The clearest available account of why network protocols work the way they do, which underpins most protocol-level security reasoning.

- [Enterprise Architecture As Strategy: Creating a Foundation for Business Execution](https://www.amazon.com/Enterprise-Architecture-Strategy-Foundation-Execution-ebook/dp/B004OC07EE): Ross, Weill and Robertson. Provides the operating model framing that determines how far security standardisation should reach.

- [The Practice of Enterprise Architecture: A Modern Approach to Business and IT Alignment](https://www.amazon.com/Practice-Enterprise-Architecture-Approach-Alignment-ebook/dp/B07BV9QCP5): Kotusev's empirical account of architecture practice, useful for positioning security architecture within the wider function.

- [An Introduction to Enterprise Architecture](https://www.amazon.com/Introduction-Enterprise-Architecture-Third/dp/1477258000): By Scott A. Bernard. A textbook treatment of frameworks, methods and governance across architecture domains.

- [Execution Architecture: The System Between Strategy and Results](https://www.amazon.com/Execution-Architecture-Between-Strategy-Results-ebook/dp/B0GYPZCZKQ): A leadership framework for understanding why strategy, including security strategy, under-converts into delivered outcomes.

## Professional development tips

- Set out a written vision and set of principles for your area, so that architects can decide consistently without you
- Work several projects at once by investing in patterns rather than by attending every design review
- Build relationships with senior stakeholders in other departments before an incident forces the conversation
- Justify innovative approaches with evidence and a fallback, since high-risk work needs a credible retreat path
- Look for the subtle security needs that nobody has articulated, because those are the ones that get missed
- Mentor security architects deliberately, and use their questions to find gaps in your own principles
- Maintain enough hands-on depth to test a claim yourself rather than relying on assurance paperwork
