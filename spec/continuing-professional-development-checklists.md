# UK GDAD PCF Continuing Professional Development

Context: United Kingdom (UK) Government Digital and Data (GDAD) Profession Capability Framework (PCF)

Goal: For every UK GDAD PCD role, provide a comprehensive markdown file for continuing professional development for person's capabilties in directory `continuing-professional-development-checklists`.

Read file `spec/continuing-professional-development-checklists-template.md`.

Research all roles, skills, job grades at `https://ddat-capability-framework.service.gov.uk/`

For each file in the directory `./continuous-professional-development-checklists`:

1. Ensure the file has a section "## UK GDAD PCF Role Skill Specifics"

2. If that section says "TODO", then research continuing professional development that is suitable for the specfic UK GDAD PCF role and skill level, and also learn about the context via corresponding files in `./assessments` and `./upskills`

3. In that section, write a comprehensive checklist of UK GDAD PCF Role Skill Specifics for continuing professional development.

Example:

- Output file `continuing-professional-development-checklists/software-development/software-developer/4-senior-developer.md`.

The output file audience is the employee worker who has the specific role.

- Tone is friendly, helpful, encouraging
- Phrasings for lower-ranking roles, such as junior roles and lesser-experience roles, is more basic.
- Phrasings for higher-ranking roles, such as senior roles and greater-experience roles, is more advance.
