# Principal data scientist - upskill resources

This page focuses on learning and growth resources for the work role of principal data scientist.

- The resources include links to online courses, blogs, research articles, videos, and books.

- These help with job upskilling, work training, professional development, and career advancement.

- These are intended to be good starting points, not a comprehensive catalogue.

At this role level you take on the most technically demanding work, set standards for others, and shape which problems data science should address. The resources below emphasise advanced method, evaluation rigour, and building technical capability in others.

We welcome constructive feedback to improve this page and these lists.

- GitHub issues and/or pull requests are welcome.

- The resources are found via AI searches then go through human-in-the-loop proofing.

## Coursera courses

- [Data Science: Statistics and Machine Learning Specialization](https://www.coursera.org/specializations/data-science-statistics-machine-learning): A Johns Hopkins specialisation covering statistical inference, regression models, machine learning and the development of data products, typically completed in three to six months.

- [Probability and Statistics for Machine Learning and Data Science](https://www.coursera.org/learn/machine-learning-probability-and-statistics): Covers probability distributions, maximum likelihood and maximum a posteriori estimation, performance assessment of models, and hypothesis testing including A/B testing.

- [Statistical Learning for Data Science Specialization](https://www.coursera.org/specializations/statistical-learning-for-data-science): From the University of Colorado Boulder, covering model selection, regression, classification, trees, support vector machines, unsupervised learning, splines and resampling methods.

## Udemy courses

- [Python for Data Science and Machine Learning Bootcamp](https://www.udemy.com/course/python-for-data-science-and-machine-learning-bootcamp/): Covers analysing data, creating visualisations and applying machine learning algorithms in Python, with over a hundred video lectures and detailed code notebooks.

- [The Data Science Course: Complete Data Science Bootcamp](https://www.udemy.com/course/the-data-science-course-complete-data-science-bootcamp/): Covers mathematics, statistics, Python, advanced statistics, machine learning and deep learning, including NumPy, pandas and scikit-learn.

- [Machine Learning, Data Science and AI Engineering with Python](https://www.udemy.com/course/data-science-and-machine-learning-with-python-hands-on/): A hands-on course covering the practical application of machine learning techniques with attention to how models behave on real data.

## Skillsoft courses

- [Courses for Data Scientist: Machine Learning Specialist](https://www.skillsoft.com/journey/data-scientist-machine-learning-ec124151-3477-44a5-b819-914e25079c6f): A career path covering data literacy, SQL, Python fundamentals, pandas, exploratory data analysis, statistics fundamentals and visualisation, then machine learning fundamentals, supervised and unsupervised learning and deep learning.

- [Courses for Data Science Foundations](https://www.skillsoft.com/journey/data-science-foundations-6cd9e7e0-0ed6-4bd3-9ca9-9b96d735ed19): Teaches cleaning, analysing and visualising data with industry-standard Python libraries including pandas and seaborn, with real-world projects.

- [Courses for Fundamental Mathematics for Data Science](https://www.skillsoft.com/journey/fundamental-mathematics-for-data-science-8803a1be-4e33-4069-b80d-4de06358ac14): Covers probability, statistics, linear algebra and calculus as applied to real data analysis, filling the gaps that limit many practitioners.

## edX courses

- [Statistics and Data Science MicroMasters (MITx)](https://www.edx.org/micromasters/mitx-statistics-and-data-science): Four courses and a proctored exam covering the fundamentals of probability and statistics alongside implementing and experimenting with data analysis techniques and machine learning algorithms.

- [Data Science: Probability (HarvardX)](https://www.edx.org/learn/probability/harvard-university-data-science-probability): Teaches probability theory through a case study on the financial crisis of 2007 to 2008, part of the Harvard data science professional certificate.

- [Probability and Statistics in Data Science using Python (UCSanDiegoX)](https://www.edx.org/learn/statistics/the-university-of-california-san-diego-probability-and-statistics-in-data-science-using-python): Teaches statistical and probabilistic approaches to understanding data, implemented in Python.

## MIT OpenCourseWare courses

- [15.097 Prediction: Machine Learning and Statistics](https://ocw.mit.edu/courses/15-097-prediction-machine-learning-and-statistics-spring-2012/): Starts with machine learning algorithms, then covers the statistical learning theory that provides their mathematical foundation, before moving into Bayesian analysis.

- [15.075J Statistical Thinking and Data Analysis](https://ocw.mit.edu/courses/15-075j-statistical-thinking-and-data-analysis-fall-2011/): Covers applied probability, sampling, estimation, hypothesis testing, linear regression, analysis of variance, categorical data analysis and nonparametric statistics.

- [18.065 Matrix Methods in Data Analysis, Signal Processing, and Machine Learning](https://ocw.mit.edu/courses/18-065-matrix-methods-in-data-analysis-signal-processing-and-machine-learning-spring-2018/): Reviews linear algebra with applications to probability, statistics and optimisation, including a full explanation of deep learning.

## Blog posts

- [Data science on the Data in Government blog](https://dataingovernment.blog.gov.uk/2023/02/14/using-data-science-for-next-gen-statistics/): Describes how the Reproducible Data Science and Analysis team applies data science and engineering skills to produce the next generation of economic statistics.

- [Data Ethics on the Data in Government blog](https://dataingovernment.blog.gov.uk/category/data-ethics/): The data ethics category of the cross-government blog, covering how ethical questions are handled in practice in UK public sector analysis.

- [Reproducible data science](https://domino.ai/blog/reproducible-data-science): Explains why reproducibility matters, and that in regulated settings every aspect of a model must be documented to provide transparency, justification and validation of how it was developed and used.

- [Reproducible data analysis](https://poldrack.github.io/psych-open-science-guide/4_reproducibleanalysis.html): From the Stanford guide to open science, covering computational reproducibility and the practices that make another researcher able to obtain identical results from your code and data.

- [Promoting and Enabling Reproducible Data Science Through a Reproducibility Challenge](https://hdsr.mitpress.mit.edu/pub/mlconlea): Describes running a reproducibility challenge and what it revealed about the state of practice.

- [Ethics in Data Analysis and Modeling](https://openstax.org/books/principles-data-science/pages/8-2-ethics-in-data-analysis-and-modeling): An open textbook chapter on ethical questions specific to analysis and modelling, rather than data collection.

- [Reproducibility on the CMU Machine Learning Blog](https://blog.ml.cmu.edu/2020/08/31/5-reproducibility/): A research-group perspective on what reproducibility requires in machine learning practice and where it commonly fails.

- [Data governance on the Government Data Architecture blog](https://dataarchitecture.blog.gov.uk/category/data-architecture/data-governance/): Covers how data governance is applied across UK government, which constrains what analysts can do with which data.

- [Data Standards on the Data in Government blog](https://dataingovernment.blog.gov.uk/category/data-standards/): Posts on data standards work across UK government, including standards that affect how analytical outputs are shared.

- [Fundamentals of Metadata Management](https://www.dataversity.net/fundamentals-metadata-management/): Covers metadata types and repositories, which determine whether a data scientist can find and trust the data they need.

## Research articles

- [Leakage and the reproducibility crisis in machine-learning-based science](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC10499856/): Documents data leakage found in 17 fields, affecting 294 papers, in some cases producing wildly overoptimistic conclusions. Essential reading before trusting a reported model score.

- [Leakage and the Reproducibility Crisis in ML-based Science (preprint)](https://arxiv.org/pdf/2207.07048): The open-access version of the above, including the model info sheets proposed as a preventive measure.

- [Reproducibility in machine-learning-based research: Overview, barriers, and drivers](https://onlinelibrary.wiley.com/doi/10.1002/aaai.70002): Reviews what blocks reproducibility in practice and what actually improves it, published in AI Magazine.

- [What is reproducibility in artificial intelligence and machine learning research?](https://onlinelibrary.wiley.com/doi/10.1002/aaai.70004): Clarifies the several distinct things people mean by reproducibility, which is a prerequisite for arguing about it usefully.

- [Pitfalls in Machine Learning Research: Reexamining the Development Cycle](https://arxiv.org/pdf/2011.02832): Argues that applied machine learning research is hindered by ad hoc design, poor data hygiene and a lack of statistical rigour in evaluation.

- [Generalizability of Machine Learning Models: Quantitative Evaluation of Three Methodological Pitfalls](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9885377/): Quantifies the effect of three common methodological errors on how well models generalise beyond their training data.

- [Cross-Validation, Risk Estimation, and Model Selection](https://arxiv.org/pdf/1909.11696): A rigorous treatment of what cross-validation actually estimates, and the conditions under which it misleads.

- [Locating ethics in data science: responsibility and accountability in global and distributed knowledge production systems](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC5124067/): Examines where responsibility actually sits in distributed data science work, which is rarely with a single individual.

- [What is Reproducibility in Artificial Intelligence and Machine Learning Research? (preprint)](https://arxiv.org/html/2407.10239v2): The open-access version, useful for readers without journal access.

- [Reproducibility in Machine Learning-based Research: Overview, Barriers and Drivers (preprint)](https://arxiv.org/html/2406.14325v1): The open-access version of the AI Magazine review of reproducibility barriers and drivers.

## Books on Amazon

- [Python Data Science Handbook: Essential Tools for Working with Data](https://www.amazon.com/Python-Data-Science-Handbook-Essential/dp/1098121228): By Jake VanderPlas. ## Professional development tips

- Set the technical standard for the team through code review, templates and shared tooling
- Choose which problems are worth data science attention, and say no to the ones that are not
- Make model monitoring and retraining part of the design, not an afterthought
- Develop others deliberately, since a principal's largest effect is through the people they raise
- Engage with data ethics governance actively rather than treating it as a compliance gate
- Publish methods and findings where colleagues across government can reuse them
- Keep reading the methodological literature, particularly on evaluation and reproducibility
