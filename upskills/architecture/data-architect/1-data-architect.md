# Data architect - upskill resources

This page focuses on learning and growth resources for the work role of data architect.

- The resources include links to online courses, blogs, research articles, videos, and books.

- These help with job upskilling, work training, professional development, and career advancement.

- These are intended to be good starting points, not a comprehensive catalogue.

At this role level you design and build data models to fulfil the organisation's strategic data needs, define and maintain the data technology architecture including metadata, integration and warehouse architecture, and support the data lifecycle in compliance with data policy. The resources below emphasise data modelling, metadata management, data standards and governance fundamentals.

We welcome constructive feedback to improve this page and these lists.

- GitHub issues and/or pull requests are welcome.

- The resources are found via AI searches then go through human-in-the-loop proofing.

## Coursera courses

- [IBM Data Architecture Professional Certificate](https://www.coursera.org/professional-certificates/ibm-data-architect): Teaches data modelling, database design and enterprise data management for building scalable and secure data systems, including data privacy measures and governance and regulatory compliance protocols.

- [Data Modeling and Architecture](https://www.coursera.org/learn/data-modeling-and-architecture): Covers creating and managing data models, exploring data relationships and schemas, alongside ethical considerations, privacy law, data governance principles and the components of a governance framework.

- [Fundamentals of Data Governance](https://www.coursera.org/learn/fundamentals-of-data-governance): Provides an overview of well-known governance frameworks including the Data Governance Institute framework and the DAMA Data Management Body of Knowledge, and explores regulations such as GDPR.

## Udemy courses

- [Data Architecture for Data Engineers: Practical Approaches](https://www.udemy.com/course/data-architecture-for-data-engineers/): Covers traditional and modern data architectures including data warehouses, data lakes and the data lakehouse, with practical treatment of data modelling, governance and security.

- [Data Warehouse: The Ultimate Guide](https://www.udemy.com/course/data-warehouse-the-ultimate-guide/): Covers data warehouse fundamentals including architecture, dimensional modelling with facts and dimensions, ETL and ELT, hands-on setup and modern cloud architectures.

- [Fundamental Course of Data Architecture 2.0 (101 level)](https://www.udemy.com/course/data-architecture-big-data-architecture-data-mesh-database-management/): An introductory course spanning data architecture, big data architecture, data mesh and database management, giving a broad orientation to the modern landscape.

## Skillsoft courses

- [Data Architecture Getting Started](https://www.skillsoft.com/course/data-architecture-getting-started-4e4297f0-0515-11e9-a572-691847e7b106): A twelve-video course covering how to define data, the data lifecycle, the importance of privacy, and SQL and NoSQL database solutions alongside key data management concepts.

- [DAMA-DMBOK Essentials: Data Management and Framework](https://www.skillsoft.com/course/dama-dmbok-essentials-data-management-framework-4faa041a-a1b4-42c7-9f83-6efe5dc9c7f8): Explores the principles of data management and the structure of the DAMA-DMBOK framework, including key roles and responsibilities and the components of the DAMA Wheel.

- [Courses for DDAT Data Architect](https://www.skillsoft.com/journey/ddat-data-architect-0044f04c-ee1e-4d2c-94a2-11c6950ea00c): A curated learning journey mapped to the UK Government Digital and Data profession capability framework for this exact role.

## edX courses

- [Databases: Modeling and Theory (StanfordOnline)](https://www.edx.org/learn/databases/stanford-university-databases-modeling-and-theory): Covers the underlying principles and design considerations of databases, including a Unified Modeling Language section introducing data modelling and how UML diagrams translate into relational schemas.

- [Relational Database Design (UMBC)](https://www.edx.org/learn/relational-databases/university-of-maryland-baltimore-county-relational-database-design): Teaches how to design relational databases including popular relational models and normal forms, so that designs conform to industry best practice.

- [Enterprise Data Management (Indiana University)](https://www.edx.org/learn/business-administration/indiana-university-enterprise-data-management): Covers data strategy and data governance, relational databases and SQL, data integration, master data management and big data technologies.

## MIT OpenCourseWare courses

- [6.830 Database Systems](https://ocw.mit.edu/courses/6-830-database-systems-fall-2010/): A graduate course on the foundations of database systems, covering relational algebra and the relational data model, schema normalisation, query optimisation and transactions.

- [1.264J Database, Internet, and Systems Integration Technologies](https://ocw.mit.edu/courses/1-264j-database-internet-and-systems-integration-technologies-fall-2013/): Covers data modelling, UML, relational databases and SQL alongside internet technologies including XML, web services and service-oriented architectures.

- [1.264J Lecture 8: Database data modeling, part 1](https://ocw.mit.edu/courses/1-264j-database-internet-and-systems-integration-technologies-fall-2013/resources/mit1_264jf13_lect_8/): The dedicated data modelling lecture from the above course, useful as a concise reference on entity relationship modelling technique.

## Blog posts

- [Government Data Architecture blog](https://dataarchitecture.blog.gov.uk/): The UK government's own data architecture blog, covering enterprise and technical principles with a focus on continuous improvement. Directly relevant context for UK public sector data architects.

- [Data governance on the Government Data Architecture blog](https://dataarchitecture.blog.gov.uk/category/data-architecture/data-governance/): The governance category of the same blog, covering how governance is applied to data architecture in a government setting.

- [Data Standards on the Data in Government blog](https://dataingovernment.blog.gov.uk/category/data-standards/): Posts on data standards work across UK government, including standards adoption and the practical problems of cross-departmental data.

- [What Is Data Architecture? Components, Principles and Examples](https://www.bmc.com/blogs/data-architecture/): A clear overview of what data architecture comprises, its principles and worked examples, useful for explaining the discipline to non-specialists.

- [6 Modern Data Architecture Principles: A Fast-Track Guide](https://data.world/blog/modern-data-architecture-principles/): Sets out principles for modern data architecture and explains the reasoning behind each.

- [How to define a Data Architecture Standard](https://medium.com/@priyankasrivastava_23895/how-to-define-data-architecture-standard-30a9d4cbc6d9): A practical account of writing a data architecture standard covering organisation, management and usage of data across an organisation.

- [Fundamentals of Metadata Management](https://www.dataversity.net/fundamentals-metadata-management/): Covers what metadata management is for, the types of metadata, and how metadata underpins discoverability and governance.

- [Data Mesh 101: Best Practices for Metadata Management](https://www.actian.com/blog/data-intelligence/data-mesh-101-best-practices-for-metadata-management/): Explains how a data mesh decentralises ownership to domain teams while maintaining interoperability through shared standards, and what that means for metadata.

- [What Is Data Mesh? A modern paradigm for data architecture and management](https://dataedo.com/blog/what-is-data-mesh-a-modern-paradigm-for-data-architecture-and-management): Introduces data mesh as the decentralised sociotechnical paradigm proposed by Zhamak Dehghani in 2019, and what changes when you adopt it.

- [Let's Architect! Modern data architectures](https://aws.amazon.com/blogs/architecture/lets-architect-modern-data-architectures/): A curated collection on modern data architecture where data is treated as a product and architectures are designed around business domains.

## Research articles

- [Conceptual Data Modelling: an empirical study of expert and novice data modellers](https://www.semanticscholar.org/paper/Conceptual-Data-Modelling:-an-empirical-study-of-Shanks/7f68ed21b4174b952f0351b898b3410b18edb6ea): Finds that models produced by expert data modellers are more correct, complete, innovative and flexible than those produced by novices, and analyses what experts do differently.

- [Improving the quality of data models: Empirical validation of a quality management framework](https://www.researchgate.net/publication/222834961_Improving_the_quality_of_data_models_Empirical_validation_of_a_quality_management_framework): Presents and empirically validates a framework for managing the quality of data models rather than relying on reviewer judgement.

- [What makes a good data model? Evaluating the quality of entity relationship models](https://link.springer.com/chapter/10.1007/3-540-58786-1_75): A foundational paper setting out quality criteria for entity relationship models and how to apply them in review.

- [Architecting Data-Intensive Applications: From Data Architecture Design to Its Quality Assurance](https://arxiv.org/pdf/2401.12011): Examines how data architecture practice affects data quality in data-intensive systems, aiming at architecture models that produce high-quality data products.

- [A Flexible and Generic Data Quality Metamodel](https://www.mitre.org/sites/default/files/pdf/07_1216.pdf): Defines the structure of metadata in a metadata repository through a metamodel of data quality entities and relationships, effectively an ontology of data quality.

- [A Conceptual Modelling Perspective for Data Warehouses](https://www.academia.edu/129108746/A_Conceptual_Modelling_Perspective_for_Data_Warehouses): Argues that conceptual modelling plays a basic role in warehouse design by providing a higher level of abstraction for describing the warehousing process and architecture.

- [Enterprise Data Modelling Methodologies: A Comparative Analysis of Inmon, Kimball, and Data Vault](https://arxiv.org/pdf/2606.29355): Compares the three dominant enterprise data modelling methodologies and the trade-offs between them.

- [Kimball's Data Warehouse Architecture: Evaluating the Challenges of Conformed Data against the Inmon Model](https://arxiv.org/pdf/2606.27571): Examines the practical challenges of conformed dimensions in the Kimball approach compared with the Inmon model.

- [Metadata Management in Data Governance: A Comprehensive Scientific Analysis](https://www.researchgate.net/publication/391179319_METADATA_MANAGEMENT_IN_DATA_GOVERNANCE_A_COMPREHENSIVE_SCIENTIFIC_ANALYSIS): A scientific examination of metadata management within the context of data governance and its organisational effects.

- [Evaluating Data Quality: Comparative Insights on Standards, Methodologies, and Modern Software Tools](https://www.mdpi.com/2079-9292/14/15/3038): An open-access comparison of data quality standards, methodologies and the tools that implement them.

## Books on Amazon

- [The Data Warehouse Toolkit: The Definitive Guide to Dimensional Modeling](https://www.amazon.com/Data-Warehouse-Toolkit-Definitive-Dimensional-ebook/dp/B00DRZX6XS): By Ralph Kimball and Margy Ross. The standard reference on dimensional modelling, covering facts, dimensions, conformed dimensions and the bus architecture.

- [Building the Data Warehouse](https://www.amazon.com/Building-Data-Warehouse-W-Inmon/dp/0764599445): By W. H. Inmon, widely described as the father of the data warehouse. Sets out the Corporate Information Factory and the relational modelling approach to warehousing.

- [Building the Data Lakehouse](https://www.amazon.com/Building-Data-Lakehouse-Bill-Inmon-ebook/dp/B09GRZ9KP3): By Bill Inmon, Mary Levins and Ranjeet Srivastava. Covers the lakehouse pattern and how it relates to the earlier warehouse and lake architectures.

- [Mastering Data Warehouse Design: Relational and Dimensional Techniques](https://www.amazon.com/Mastering-Data-Warehouse-Design-Dimensional/dp/0471324213): By Claudia Imhoff, Nicholas Galemmo and Jonathan Geiger. Merges Inmon's warehouse design philosophy with Kimball's data mart philosophy into one coherent approach.

- [The DAMA Guide to the Data Management Body of Knowledge](https://www.skillsoft.com/book/the-dama-guide-to-the-data-management-body-of-knowledge-dama-dmbok-guide-first-edition-cc095fa0-f038-11e6-87f4-0242c0a80606): The reference text for the knowledge areas of data management, including data architecture, modelling, storage, security, integration, metadata and quality.

- [Enterprise Architecture As Strategy: Creating a Foundation for Business Execution](https://www.amazon.com/Enterprise-Architecture-Strategy-Foundation-Execution-ebook/dp/B004OC07EE): By Ross, Weill and Robertson. Provides the operating model framing that determines how much data integration and standardisation an organisation actually needs.

- [Business Architecture: A Comprehensive Guide](https://us.amazon.com/Business-Architecture-comprehensive-Jonathan-Hunsley-ebook/dp/B0D2V1F5N5): Useful for data architects who need to connect data models to business capability and value stream views.

- [Operating Model Canvas: aligning operations and organization with strategy](https://www.amazon.com/Operating-Model-Canvas-Haren-Publishing/dp/9401800715): A framework for describing how an organisation works, including its information dimension, which grounds data architecture in operational reality.

- [The Practice of Enterprise Architecture: A Modern Approach to Business and IT Alignment](https://www.amazon.com/Practice-Enterprise-Architecture-Approach-Alignment/dp/0645082538): By Svyatoslav Kotusev. Empirically grounded account of which architecture artefacts actually get used in organisations.

- [Business Model Generation: A Handbook for Visionaries, Game Changers, and Challengers](https://www.amazon.com/Business-Model-Generation-Visionaries-Challengers-ebook/dp/B06X426D4F): By Osterwalder and Pigneur. A quick way to frame the business context that a data model has to serve.

## Professional development tips

- Model the business meaning first and the storage technology second, because storage choices change more often than meaning does
- Write definitions for every entity and attribute, since an undefined field becomes a data quality incident later
- Learn at least one modelling notation precisely, and be able to explain a model to a non-technical stakeholder in plain words
- Treat metadata as a product with users, not as documentation produced once and abandoned
- Read your organisation's data policy and be able to say exactly how your design complies with it
- Follow the UK government data architecture and data standards blogs to stay aligned with cross-government direction
- Practise reviewing other people's models, because critique sharpens your own design judgement faster than building alone
